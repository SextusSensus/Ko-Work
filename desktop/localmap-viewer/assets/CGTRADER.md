# CGTrader shortlist — Local Map (hub / kitchen / indoor / robot)

**Policy:** CGTrader is a commercial marketplace. Paid models are **link-only** until Todd licenses them. Free CGTrader listings use **Royalty Free** terms that **forbid redistributing source files** in this repo — they are marked `free_download` (Todd may download for local licensed use) but **binaries are never committed**. Ship CC0 (Poly Haven / ambientCG / Kenney) as runtime fallbacks.

Statuses: `link_only` | `free_download` | `purchased_placeholder` | `local`

Drop a purchased GLB into `assets/library/<id>/model.glb` and flip the catalog entry `status` → `local` (see [README-UI.md](../../README-UI.md#purchased-cgtrader--local-glb-drop-in)).
